# SIMA organization defaults

هذا المستودع هو طبقة المنظمة المشتركة لسِمَة على GitHub.

يحتوي فقط على ملفات افتراضية آمنة وقابلة لإعادة الاستخدام عبر مستودعات `sima-hq`، مثل ملف المنظمة، إرشادات المساهمة، الأمان، الدعم، وقوالب القضايا العامة.

## الحدود

- الكود، المعمارية، القرارات، الحوكمة التشغيلية، إجراءات GitHub Actions الخاصة بالمنتج، وحقائق التشغيل الحية تبقى داخل المستودع المختص بها.
- المستودع الكنسي الحالي للمنتج هو `sima-hq/Sima`.
- أي ملف خاص بمستودع معيّن له الأولوية على الافتراضي الموجود هنا.
- لا تُخزّن أسرار، مفاتيح، بيانات شخصية، أو تفاصيل تشغيلية حساسة في هذا المستودع.

## البنية

- `profile/README.md` — تعريف المنظمة.
- `CONTRIBUTING.md` — قواعد المساهمة المشتركة.
- `SECURITY.md` — سياسة الإبلاغ الأمني العامة.
- `SUPPORT.md` — مسار طلب الدعم.
- `.github/ISSUE_TEMPLATE/` — قوالب قضايا افتراضية للمستودعات التي لا تملك قوالبها الخاصة.

> ملاحظة: لكي يستخدم GitHub هذا المستودع فعليًا كمصدر للملفات الافتراضية على مستوى المنظمة، يجب أن تكون رؤية المستودع مناسبة لقواعد GitHub الخاصة بمستودع `.github`.
